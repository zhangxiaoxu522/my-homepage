[README.md](https://github.com/user-attachments/files/34951531/README.md)# 我的个人主页

这是通过 GitHub 作业创建的第一个仓库，用于练习 Git 与 GitHub 的基本操作。

## 项目内容

- `index.html` —— 一个简洁的个人主页，可直接在浏览器中打开，也可通过 GitHub Pages 发布上线。

## 如何修改

1. 打开 `index.html`，把 `[你的姓名]`、`your-email@example.com`、`https://github.com/你的用户名` 替换成你自己的信息。
2. 提交更改：

```bash
git add index.html
git commit -m "Update personal info"
git push
```

## 如何发布为网站

在 GitHub 仓库页面：**Settings → Pages → Source 选择 main 分支 → Save**，
几分钟后访问 `https://你的用户名.github.io/仓库名/` 即可看到你的主页。
